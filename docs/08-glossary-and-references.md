# 8. Glossary and References

## Glossary
- **ASCII art:** Visual output represented with text characters.
- **Canvas 2D:** Browser API for drawing text and images.
- **Density map:** Ordered character set used to encode brightness.
- **Temporal smoothing:** Blending a frame with the prior frame to reduce jitter.
- **MediaDevices API:** Browser interface used to request camera access.
- **Data URL:** String representation embedding data, used for canvas PNG capture.
- **Vite:** Development server and build tool used by this project.
- **Gemini API:** Google's generative AI service used for scene analysis.
- **Threat level:** Model-generated string, not a verified classification here.
